# StudyHub agent rules

This repository follows the supplied StudyHub specification: zero-cost services only, Next.js App Router with strict TypeScript, Tailwind and Shadcn-style reusable UI, Supabase PostgreSQL with Supabase Auth Google OAuth, mobile-first layouts, and PWA installability. Do not modify the schema in `supabase/migrations/0001_init.sql` without explicit approval. Prefer server components for reads and authenticated server actions for mutations. Run typecheck and production build before delivery.
